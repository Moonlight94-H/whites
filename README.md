## 本地预览
1. 解压 ZIP。
2. 双击 `index.html`，使用现代浏览器打开。
3. 请保持 `assets` 文件夹、`index.html`、`projects.js`、`script.js`、`styles.css` 位于同一项目目录结构中。

## 发布到 GitHub Pages
将解压后的全部文件和 `assets` 文件夹上传到仓库根目录，在 GitHub 仓库 Settings → Pages 中选择从 `main` 分支的 `/ (root)` 部署。
